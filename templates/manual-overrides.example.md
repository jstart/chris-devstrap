# Manual follow-ups (personal overrides)

Copy items you care about into your own notes, or append lines via `chris_manual_todo` in a local fork.
The guided bootstrap checklist already covers iTerm, Raycast, Git identity, Apple ID + App Store, and Xcode.

## Google Chrome — profile example

Open Chrome → profile menu → Add / Sign in → complete sign-in for your account (e.g. `you@example.com`); optional profile name/avatar.

## Apple ID / iCloud — Calendar + Contacts

**System Settings → Apple ID → iCloud:** enable Calendars, Contacts, etc.; disable Mail/Notes/iCloud Drive if unwanted. Mirror on iPhone if needed.
