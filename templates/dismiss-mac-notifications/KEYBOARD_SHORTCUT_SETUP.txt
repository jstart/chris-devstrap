Dismiss Mac Notifications — bind ⌘⌃Z (Command + Control + Z)
=============================================================

Recommended hotkey: ⌘⌃Z. Bootstrap guides the **Raycast Script Commands** path
(in the Raycast checklist step). This file is the offline copy installed at
~/bin/DismissMacNotifications/KEYBOARD_SHORTCUT_SETUP.txt — including the
Shortcuts.app fallback (not shown in the guided checklist).

Two paths — pick one (or both):

A) Raycast Script Commands (preferred — automated install)
----------------------------------------------------------
chris-devstrap drops a Raycast script command into
  ~/Library/Application Support/chris-devstrap/raycast-script-commands/
(see scripts/raycast-script-commands.sh). Then, in Raycast:

1) Settings (⌘,) → Extensions → Script Commands → "+" → User Folder
   → choose the directory above.
2) Extensions → search "Dismiss Mac Notifications" → click the Hotkey field
   → press ⌘⌃Z.
3) First run: grant Accessibility to Raycast
   (System Settings → Privacy & Security → Accessibility).

B) Shortcuts.app (built-in macOS, no extra app)
-----------------------------------------------
1) Open Shortcuts.app → File → New Shortcut (⌘N).
2) Add Action: search "Run Shell Script" and add it.
3) In Run Shell Script:
   - Shell: /bin/bash
   - Pass Input: (default is fine)
4) Script body (one line):
     $HOME/bin/DismissMacNotifications/dismiss-notifications.sh
   (Or the absolute path from: ls -la ~/bin/DismissMacNotifications/dismiss-notifications.sh)
5) Rename the shortcut to: Dismiss Mac Notifications
6) Open Shortcut Details (ⓘ) → Add Keyboard Shortcut → press ⌘⌃Z.
7) First run: grant Accessibility to Shortcuts
   (System Settings → Privacy & Security → Accessibility).

Run without a hotkey:
  dismissnotifications                          # zsh function appended by chris-devstrap
  shortcuts run "Dismiss Mac Notifications"    # only after path B above
